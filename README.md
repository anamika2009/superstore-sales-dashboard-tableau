📊 Superstore Sales Dashboard

An interactive Superstore Sales Dashboard created using Tableau to analyze sales, profit, orders, returns, product performance, and regional/category-level business performance.

**1 Project Overview**

This project uses the Sample Superstore dataset provided by Tableau. The dataset contains information about orders, customers, products, sales, profit, discounts, shipping, categories, regions, and returns.
The dashboard transforms this data into interactive visualizations and key performance indicators (KPIs) to make sales and business performance easier to understand.

The Tableau Superstore dataset is commonly used for learning and demonstrating data analysis and visualization because it contains multiple dimensions, measures, dates, geographical information, and profit-related data.

**4 Key Insights**

* The dashboard provides a clear comparison of sales and profit performance across different categories and sub-categories.
* Profit margin and return rate help identify overall business profitability and return performance.
* The Top 5 Products view highlights the products contributing strongly to business performance.
* The geographic map helps identify regional sales patterns.
* Year-over-year analysis provides a view of profit growth and changes in business performance.
